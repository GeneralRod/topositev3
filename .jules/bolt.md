## 2024-05-15 - React-Leaflet Event Handlers Re-attaching\n**Learning:** Using inline object definitions `eventHandlers={{ click: ... }}` in `react-leaflet` components causes Leaflet event listeners to be removed and re-added on every re-render. A `useMemo` dependency check will fail if the dependencies are object literals that are created every render.\n**Action:** Use `useMemo` with correct dependency array bounds to memoize the event handler objects to avoid expensive DOM event re-attachments and use `useRef` + `useLayoutEffect` to stable event handler callbacks correctly.
