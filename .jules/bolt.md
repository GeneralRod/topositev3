## 2025-02-19 - React-Leaflet Event Handlers Re-render Problem\n**Learning:** Passing inline objects to `eventHandlers` in `react-leaflet` components (e.g. `<Marker eventHandlers={{ click: () => ... }} />`) causes Leaflet to remove and re-attach event listeners on every re-render. This leads to a severe performance bottleneck due to excessive DOM manipulation.\n**Action:** Always extract and memoize `eventHandlers` objects using `useMemo` combined with stable references (via `useRef` and `useLayoutEffect` for handlers that depend on changing props or state) when using `react-leaflet`.
