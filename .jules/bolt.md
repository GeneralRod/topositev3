## 2025-02-18 - Memoize Leaflet Event Handlers
**Learning:** Passing inline objects to `eventHandlers` in `react-leaflet` components (like `<Marker>` or `<GeoJSON>`) is a severe performance anti-pattern. Because the object reference changes on every render, Leaflet continuously removes and re-attaches the event listeners to the DOM elements. This causes O(n) DOM operations per render for lists of markers or shapes, creating significant lag.
**Action:** Always extract `eventHandlers` into a `useMemo` block or create separate memoized components for elements with event handlers. If the handlers depend on changing props (like callbacks), use a `useRef` + `useLayoutEffect` pattern to maintain a stable reference to the callback without breaking the memoization of the `eventHandlers` object.
